1. Test.py
•	Основной скрипт для демонстрации работы системы.
•	Генерирует код для задания "Угадайка числа в консоли" с помощью CodeProcessor.
•	Модифицирует код, добавляя "шум" (ошибки и лишние элементы) через task_type="noise".
•	Сохраняет результаты:
o	Модифицированный код в result/input.txt.
o	Промежуточные данные (промпты) в JSON-файлы.
________________________________________
2. Utils.py
•	Вспомогательные функции:
o	load_text_from_file — загрузка текста из файла.
o	save_json, save_text_as_txt — сохранение данных в JSON и TXT.
o	is_code_syntax_valid — проверка синтаксиса кода через ast.parse.
o	SH — сокращение строк для логов.
o	get_resource_path — работа с путями (поддержка PyInstaller).
________________________________________
3. CodeProcessor.py
•	Ядро системы для взаимодействия с YaGPT:
o	Класс CodeProcessor:
	Настройка подключения к YaGPT (API-ключ, модель yandexgpt-lite).
	Методы:
	generate_code_for_task — генерация кода по описанию (например, "Угадайка числа").
	process_code — модификация кода (пропуски, шум, ошибки) на основе:
	Промптов из файлов (GapsPrompt.txt, NoisePrompt.txt).
	Параметров: сложность (difficulty), тип задачи (task_type).
	Проверка синтаксиса (до 3 попыток при ошибках).
o	Класс PromptBuilder — сборка промптов из файлов и текста.
________________________________________
4. Logger.py
•	Настройка цветного логирования с фильтрацией по проекту:
o	Вывод времени, уровня (INFO, WARNING) и сообщений.
o	Отключение сторонних логов.
________________________________________
5. Текстовые файлы с промптами
•	Common.txt — общие инструкции для YaGPT.
•	GapsPrompt.txt — шаблон для создания заданий с пропусками (___).
•	NoisePrompt.txt — шаблон для добавления шума (ошибки, лишние строки).
•	GenerateCodeForTask.txt — инструкция для генерации кода.
_______________________________________
6. Файлы Case.txt, Time.txt и Text.txt — это примеры исходного кода, которые используются как образцы для модификации или как референсы при генерации новых заданий. Они не являются промптами (в отличие от файлов в папке Prompts), а содержат корректный код, который система может:
1.	Взять за основу для создания заданий (пропуски, шум).
2.	Использовать как шаблон при генерации похожего кода.
________________________________________   
Как это работает?
1.	Генерация кода:
o	CodeProcessor отправляет описание задания (например, "Угадайка числа") в YaGPT.
o	Получает чистый код (пример в result 2025-04-19T13-28-45.txt).
2.	Модификация кода:
o	Добавляет шум/ошибки через process_code (например, спагетти-код).
o	Использует промпты, чтобы указать YaGPT тип изменений.
3.	Сохранение результатов:
o	Код и логи сохраняются в папку result.
________________________________________
Интеграция с YaGPT
•	В CodeProcessor.py указаны параметры подключения:
o	folder_id, auth (API-ключ).
o	Модель: yandexgpt-lite с температурой 0.3 для детерминированности.
•	Запросы отправляются через YCloudML (Yandex Cloud ML SDK).
